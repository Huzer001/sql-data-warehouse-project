# Projet Data Warehouse et Analytics

Bienvenu sur mon répertoire **Projet Data Warehouse et Analytics** !🚀
Ce projet démontre une solution d'entreposage de données et analytics compréhensive, de la conception d'un entrepôt de données à la génération d'informations exploitables.

## 🚀 Prérequis du projet

### Construire le data warehouse (Data Engineering)

#### Objectif
Développer un data warehouse moderne en utilisant SQL Server pour consolider les données de ventes, et permettre un reporting analytique et la prise de données basée sur les données.

#### Spécifications
- **Sources de données**: Importer les données depuis deux sources système (ERP et CRM) fournies sous format CSV.
- **Qualité des données**: nettoyer et résoudre les problèmes de qualité des données avant de procéder à l'analyse.
- **Intégration**: combiner les sources en une seule, modèle de données facile à comprendre conçu pour les requêtes d'analyse.
- **Périmètre**: se concentrer uniquement sur les derniers jeux de données ; l'historisation des données n'est pas requise.
- **Documentation**: fournir une documentation claire du modèle de données pour aider les parties prenantes business et l'équipe analytique.

---

### BI: Analytics & Reporting (Data Analytics)

#### Objectif
Développer des outils d'analyse basés sur SQL afin de fournir des informations détaillées sur:
- **Customer Behavior**
- **Product Performance**
- **Sales Trends**

Ces informations fournissent aux parties prenantes des indicateurs clés de performance, leur permettant ainsi de prendre des décisions stratégiques.
